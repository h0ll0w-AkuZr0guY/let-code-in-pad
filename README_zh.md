# Let Code in Pad 🚀

一个轻量级、完全离线、专为平板优化的跨端个人知识库。

**Let Code in Pad (LCP)** 专为 **“电脑端录入，平板端复习与管理”** 的工作流量身定制。它让你无需配置任何后端服务器和数据库，就能极其优雅地管理算法题、面经笔记，甚至私人日记。

## ✨ 核心特性

- 🌌 **平行空间架构**：在个人中心双击头像，即可在 **技术区**（算法/面经）与 **生活区**（日记/手账）之间无缝切换。支持设定默认启动空间，保护个人隐私。
- 💾 **混合存储黑科技**：彻底告别数据库！电脑端利用自定义 Vite 插件直接物理覆写 `data.json` 与图片文件；平板/手机端自动降级使用 IndexedDB 实现极速离线增删改查。
- 📤 **纯前端原生导出**：一键将整个分类或单篇笔记导出为 **Markdown** 或 **高清 PDF**。底层的异步内联引擎会在导出瞬间将所有本地图片转码为 Base64，确保发送给任何人都不“图裂”。
- 📦 **LCP 数据流转协议**：基于剪贴板的跨端神器。长按卡片复制 LCP 协议数据包，在另一台设备的顶栏点击“导入”，即可瞬间还原图文并茂的完整记录。
- 📱 **原生级交互体验**：
  - **长按菜单**：长按卡片 0.6 秒呼出精美底部菜单（置顶、编辑、分享、移入回收站）。
  - **悬浮翻页**：屏幕两侧预留专供大拇指握持点击的透明悬浮按键，彻底解决滑动冲突。
  - **沉浸式 UI**：完美规避刘海屏遮挡，隐藏全局丑陋滚动条，移动端自动强制锁定横屏。
- 🎨 **标签色盘与防误删**：内置原生取色器自由定制标签高亮色；所有删除操作均移入“回收站”，提供一键恢复功能。

## 🛠️ 技术栈

- **前端框架**：Vue 3 (Composition API) + Vite
- **UI & 样式排版**：Tailwind CSS + `@tailwindcss/typography`
- **内容解析**：`markdown-it` + `highlight.js` + `turndown` (支持富文本粘贴自动转 MD)
- **跨平台打包**：Capacitor (`@capacitor/app`, 剪贴板, 屏幕方向锁定)
- **本地存储**：`localforage` + Vite 本地写盘中间件

## 🚀 快速开始

### 1. 环境准备
- 确保电脑已安装 Node.js。
- 若需打包 APK，请提前安装 Android Studio。

### 2. 安装项目
``` bash
git clone https://github.com/h0ll0w-AkuZr0guY/let-code-in-pad.git
cd let-code-in-pad
npm install
```

### 3. 电脑端生产 (录入工作流)


​``` bash
npm run dev
```

- 在浏览器打开 `http://localhost:5173`。
- 直接截图粘贴、书写代码，点击保存，数据瞬间物理固化到本地电脑文件夹。

### 4. 平板端消费 (打包 APK)

``` bash
npm run build
npx cap sync
npx cap open android
```

*在 Android Studio 中点击 Build 即可生成属于你的离线平板 App！*
